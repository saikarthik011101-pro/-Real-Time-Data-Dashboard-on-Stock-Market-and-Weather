📊 Real-Time Data Analytics Dashboard

📌 Overview
This project is a Streamlit-based interactive dashboard that integrates stock market data (via Alpha Vantage API) and weather information (via OpenWeatherMap API). It provides real-time insights with visualizations powered by Plotly.

⚙️ Features
Stock Analytics

Fetches intraday stock prices for multiple symbols.

Interactive line charts of closing prices.

Real-time metrics for current stock values.

Weather Insights

Displays temperature, humidity, wind speed, and conditions for any city.

Auto-refresh option for updated data.

Dashboard

Built with Streamlit for a clean, responsive UI.

Sidebar controls for stock symbols, city, and refresh.

🛠️ Tech Stack
Python (Streamlit, Plotly, Pandas, Requests)

APIs

Alpha Vantage (stock data)

OpenWeatherMap (weather data)

Utilities

Tenacity (retry logic)

dotenv (environment variable management)
